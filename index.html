Vowels Cards

These cards present the vowels activity screens with details about how the vowel counter works.

vowels.png

Vowel Counter Screen

This view accepts a text input and scans each character to count vowels. The app checks letters and updates totals for A, E, I, O, and U after processing the entered word or phrase.

vowels1.png

Vowel Counter Result

This output card shows the computed result format. Each vowel has its own count so users can immediately see distribution, such as how many times O appears compared with A, E, I, and U.

Prime Number Cards

These cards show how the prime-number checker takes input and returns the result.

This screen asks for a number and starts checking divisibility from 2 up to the square root of the input. If a divisor is found, the number is marked as not prime.

Prime Checker Result

This result view displays whether the entered number is prime or composite. It summarizes the final decision after the divisibility checks are completed.
